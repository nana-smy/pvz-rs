# 植物大战僵尸 · Rust 重制版

用 Rust 重写《植物大战僵尸》的经典草坪关卡，编译成 WebAssembly，在浏览器里直接游玩。植物立绘、僵尸整身拼装图、白天/黄昏/夜晚前院背景与全套 WAV 音效均来自授权原版素材；阳光、豌豆、粒子与 HUD 由 Canvas 2D 绘制。

在线试玩：<https://nana-smy.github.io/pvz-rs/>

## 玩法

- 5 行 × 9 列草坪，按原版 1073 的波次点数出怪：白天 4 波、黄昏 6 波、夜晚 8 波。
- 波内不再按固定数量硬刷，而是像原版一样按点数预算挑选僵尸；旗帜波先补普通僵尸，再出旗帜僵尸。
- 每关开始前先选种子：只在关卡解锁的植物池里挑选，卡槽数量逐关增加（6 / 7 / 8）。
- 战斗中点击顶部卡片选择植物，再点草坪格子种下；右键取消选择。
- 阳光：天上会掉，向日葵也会产；**点一下就能收**，16 秒不捡会消失。
- 铲子可以铲掉种错的植物。
- 每行末尾有一台割草机，僵尸靠近时自动冲出去清掉这一行的僵尸，只能用一次。

僵尸有普通、路障、铁桶、旗帜、撑杆跳、铁门、橄榄球、梯子八种。血量与速度按零售 1073：普通本体 200，路障帽 370，铁桶 1100，铁门 1100，扶梯 500 本体 + 500 梯子；普通/路障/铁桶/铁门每只随机 23–37 px/s，旗帜 45，撑杆与橄榄球 66–68，扶梯 79–81。

本作压缩成三关，因此旗帜波按“首周目不足 10 波”的原版规则放在各关最后一波：白天 1-1 没有旗帜波，黄昏与夜晚最后一波为旗帜波，并补齐本关允许但尚未出场的僵尸。

## 关卡

| 关卡 | 波数 | 初始阳光 | 特点 |
| --- | --- | --- | --- |
| 白天 · 前院 | 4 | 75 | 对应 1-1 节奏，6 个卡槽；仅普通僵尸，前 3 波各 1 只 |
| 黄昏 · 前院 | 6 | 90 | 对应 1-2 节奏，7 个卡槽；末波旗帜波 |
| 夜晚 · 前院 | 8 | 100 | 对应 1-3 节奏，8 个卡槽；没有天降阳光；末波旗帜波 |

在标题页点击关卡后先进入选种界面，选满卡槽再点“开始战斗”。通关后进入下一关，失败后回到本关重新选种。

关卡波次遵循原版 1073 的 `aWave / 3 + 1` 点数模型，首波 18 秒，普通波间隔 25–31 秒，旗帜波前留 45 秒。种子包冷却也按原表改为 0.75 秒至 5 秒，不再使用旧版的 5–30 秒长冷却。

## 操作

- 鼠标：选卡 / 种植 / 收阳光 / 点按钮
- `空格` 选种界面直接开始；战斗中暂停或继续
- `R` 重开本关
- `Esc` 取消选择 / 暂停
- `M` 静音
- `D` 调试信息（开发用）

## 技术栈

- **Rust** 负责全部游戏逻辑（状态机、波次、碰撞、经济、音效触发）
- **wasm-bindgen + web-sys** 做浏览器绑定
- **Canvas 2D** 渲染，无 WebGL 依赖
- **原版素材**：`assets/plants/` 十四种植物立绘，`assets/zombies/` 七种僵尸整身拼装图，`assets/bg/` 三套前院背景，`assets/audio/` 原版 WAV 音效与循环 BGM（经素材提供方授权使用）
- **WebAudio** 作为缺失音效时的合成回退
- 逻辑分辨率 1280×720，页面按 16:9 等比缩放，支持窗口尺寸变化

项目结构：

```
src/defs.rs     常量、数值、UI 布局
src/game.rs     游戏状态机与全部玩法逻辑
src/render.rs   Canvas 2D 绘制（优先绘制原版植物立绘）
src/assets.rs   原版图片资源句柄
src/sfx.rs      原版音效播放 + WebAudio 合成回退
src/main.rs     wasm 入口、输入事件、requestAnimationFrame 主循环
web/index.html  页面外壳、素材预加载、等比缩放
assets/         授权原版植物立绘与音效
```

## 本地运行

前置：Rust stable、`wasm32-unknown-unknown` target、`wasm-bindgen-cli 0.2.130`。

```bash
rustup target add wasm32-unknown-unknown
cargo install wasm-bindgen-cli --version 0.2.130   # 或下载 release 里的预编译包
./build.sh
python3 -m http.server 8765 --directory dist
# 打开 http://localhost:8765/
```

## 部署

仓库已配置 `.github/workflows/pages.yml`：推送到 `main` 后自动编译 wasm、生成 `dist/` 并发布到 GitHub Pages（Source 选 GitHub Actions）。也可以在仓库 Settings → Pages 里手动触发 workflow。

## 素材说明

`assets/plants/` 与 `assets/audio/` 为素材提供方授权使用的《植物大战僵尸》原版资源，仅用于本项目展示；版权归原权利人所有。素材包内没有普通/路障/铁桶/旗帜僵尸的完整动画帧或全尸立绘，因此僵尸仍由代码绘制。
